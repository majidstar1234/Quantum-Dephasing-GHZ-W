# Quantum Entanglement Robustness under Dephasing

This repository contains the code, figures, and LaTeX source for the paper:

**"Robustness of Multipartite Entanglement under Independent and Correlated Dephasing: Implications for Quantum Repeaters and Sensing"**  
*Author: Amir Reza Babaei*  
*Email: tabanafraz@gmail.com*

## Structure
- `src/` – LaTeX source files and simulation scripts (QuTiP/Python).
- `figures/` – Generated figures (PDF format).
- `docs/` – Compiled paper PDF.
- `tables/` – Extracted tables in LaTeX and CSV formats.

## Requirements
- Python 3.x with QuTiP, NumPy, Matplotlib.
- LaTeX distribution (for compilation).

## Usage
Run the simulation scripts in `src/` to reproduce the data, then compile `main1.tex` to generate the paper.
